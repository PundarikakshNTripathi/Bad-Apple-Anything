# Bad Apple Anything

A pipeline that reconstructs a source video's subject as a vector
silhouette animation, synced to the video's own extracted audio, and
renders it procedurally rather than replaying source pixels.

Rename this codename before publishing if desired; it exists to avoid
naming the tool after any specific copyrighted work it can process.

## Status

Phase in progress. See `docs/03_SDD.md` section 8 for the phase
breakdown and `CHANGELOG.md` for what has landed so far.

## Requirements

- Rust, stable toolchain, 2021 edition or newer.
- Python 3.11 or newer.
- `ffmpeg` >= 6.0 on `PATH`.
- A Vulkan, Metal, or DirectX 12 capable GPU for the accelerated render
  path. Falls back to a software rasterizer automatically if unavailable,
  logged at warning level.

## Setup

See `docs/08_VIBE_CODING_GUIDE.md` for the full setup and development
workflow, including what is scripted for you versus what you configure
yourself.

Quick start once dependencies are installed:

```
cargo build --release
python -m pip install -e python/baa_ingest
```

Place a source video at `assets/source.mp4` (this path is git-ignored and
never committed, see `docs/adr/ADR-0007-test-fixture-policy-no-copyrighted-media-in-vcs.md`).

```
./target/release/baa run --input assets/source.mp4 --out out/
```

Output is written to `out/final.mp4`.
